
# FitLife Fitness Gym Website

## 1. Project Overview

FitLife Fitness Gym is a website developed to provide information about the gym and its services. The website helps visitors learn about the organisation, explore available services and contact the gym.

The website uses HTML, CSS and JavaScript.

## 2. Website Goals

The main goals of the website are:

- Provide information about FitLife Fitness Gym.
- Display the services offered by the gym.
- Allow visitors to make enquiries.
- Provide contact information and location details.
- Create a website that works on computers, tablets and mobile phones.

## 3. Website Pages

The website contains the following pages:

- **Home:** Introduces FitLife Fitness Gym.
- **About Us:** Explains the organisation, mission and vision.
- **Services:** Displays the services offered.
- **Enquiry:** Allows visitors to submit an enquiry.
- **Contact:** Provides contact details and a message form.
- **Sitemap:** Helps visitors navigate the website.

## 4. Technologies Used

The following technologies were used:

- HTML5 – Used to structure the website.
- CSS3 – Used to style the website and create a responsive layout.
- JavaScript – Used to add interactive features and form validation.
- OpenStreetMap – Used to display a map.
- GitHub – Used to store and manage project files.

## 5. JavaScript Features

The website includes:

- FAQ accordion that opens and closes questions.
- Service search functionality.
- Enquiry form validation.
- Contact form validation.
- Email preparation through the visitor's email application.

## 6. Search Engine Optimisation (SEO)

SEO improvements include:

- Page titles and meta descriptions.
- Relevant keywords.
- Proper heading structure.
- Alternative text for images.
- Internal links between website pages.
- Mobile-friendly design.
- XML sitemap and robots.txt files.

## 7. Responsive Design

The website uses CSS media queries to adjust its layout for different screen sizes.

It supports:

- Desktop computers.
- Tablets.
- Mobile phones.

## 8. How to Run the Website

1. Download or clone the project from GitHub.
2. Open the project folder in Visual Studio Code.
3. Open the index.html file in a web browser.
4. Use the navigation menu to explore the website.

## 11. Limitations

The enquiry and contact forms use mailto links to prepare emails. They do not store information in a database or automatically send messages.

The gym address and map location should be confirmed before the website is published.

## 12. Conclusion
